# Fire Arena Hub — Tournament Platform

A full-stack web app for managing online gaming tournament registrations, player stats, and prize pools.

> This repo is linked to the Fire Arena project from my resume — built as a practical MERN + Python learning project.

## Tech Stack
- **Frontend:** React.js, TypeScript, HTML, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** Python (data sorting scripts)

## Features
- User sign-up / registration for tournaments
- Player statistics tracking
- Prize pool display
- Admin panel to monitor users

## How to Run
```bash
# Install dependencies
npm install
# or
pnpm install

# Start dev server
npm run dev
```

## Project Structure
- `/lib` — shared utilities
- `/scripts` — helper scripts
- `/artifacts` — build artifacts
- `/attached_assets` — images/assets
